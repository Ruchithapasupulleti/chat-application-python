# Chat Application (Python)

A real-time multi-client chat application built using Python socket programming, enabling users to communicate over a network.

## Features
- Multi-client support
- Real-time messaging
- Threading for handling multiple users
- Client-server architecture

## Technologies Used
- Python
- Socket Programming
- Threading

## Concepts Used
- Socket Programming
- Client-Server Architecture
- Multithreading
